# Пары — расписание БПИ25-01 для iPhone

Веб-приложение (PWA): открывается с иконки на экране «Домой», работает без интернета

## Файлы
- `index.html` — всё приложение: вёрстка, стили, логика
- `data.json` — расписание, собирается парсером
- `parse.py` — парсер страницы СибГУ → `data.json` + календари `schedule*.ics`
- `sw.js` — service worker, кэш для работы офлайн
- `manifest.webmanifest`, `icon-*.png` — иконка и название на экране «Домой»
- `update.sh` — обновить расписание с Мака одной командой
- `.github/workflows/update.yml` — автообновление раз в день (если сайт пускает GitHub)

## Проверка в браузере
`python3 -m http.server` в папке проекта, потом http://localhost:8000/?now=2026-09-29T10:15
(параметр `now` подменяет текущее время)
